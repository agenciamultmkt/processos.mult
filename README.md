# Processos — Agência Mult

Repositório com o passo a passo padrão e os arquivos-modelo (editáveis) de cada etapa do ciclo do colaborador na agência — do briefing da vaga até a gestão do dia a dia em loja.

## Como usar

- Cada pasta numerada é uma etapa do processo. Dentro dela: `passo-a-passo.md` (o checklist da etapa) e `modelos/` (os arquivos que você preenche a cada vaga/colaborador).
- Para editar um `passo-a-passo.md`: abra o arquivo aqui no GitHub e clique no ícone de lápis ("Edit this file") — não precisa saber usar git.
- Para usar um modelo: baixe o arquivo de `modelos/`, preencha no Word/Excel normalmente, e suba a versão preenchida de volta arrastando o arquivo pela interface do GitHub (ou guarde numa pasta local separada, fora do repositório).

## Etapas

1. [Contratação](01-contratacao/passo-a-passo.md) — do briefing da vaga até a admissão
2. [Onboarding](02-onboarding/passo-a-passo.md) — textos, cartas, uniforme, EPI
3. [Gestão](03-gestao/passo-a-passo.md) — Trade Pro, grupos, monitoramento

## Nota importante

Os arquivos dentro de `modelos/` são **modelos em branco** — evite sobrescrever o modelo original com os dados de um colaborador específico. Se quiser manter os arquivos já preenchidos versionados aqui também, crie uma pasta `preenchidos/` dentro de cada etapa (isso não veio nesta primeira versão — é só puxar quando fizer sentido).
