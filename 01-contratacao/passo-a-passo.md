# 1. Contratação

Do briefing da vaga até a admissão do colaborador.

## 1.1 Briefing da vaga
- [ ] Confirmar com o cliente/coordenadora: cargo, loja(s), carga horária, salário, data de início desejada
- [ ] Preencher `modelos/briefing-vaga.docx` com os dados acima
- [ ] Definir canal(is) de divulgação (OLX, indicação interna, outros)

## 1.2 Divulgação da vaga
- [ ] Publicar no OLX — usar uma das contas dedicadas (rodízio de contas em uso)
- [ ] Divulgar nos demais locais de captação de currículo ativos
- [ ] Usar o roteiro padrão de abordagem ao colaborador (roteiro UAU já padronizado)

## 1.3 Recrutamento
- [ ] Triagem dos currículos recebidos
- [ ] Entrevista (presencial ou por telefone)
- [ ] Registrar os candidatos avaliados em `modelos/checklist-recrutamento.xlsx`

## 1.4 Documentação e exames
- [ ] Solicitar documentos do candidato aprovado (RG, CPF, comprovante de residência, dados bancários)
- [ ] Agendar ASO em clínica parceira
- [ ] Confirmar o resultado do ASO antes de prosseguir

## 1.5 Admissão
- [ ] Preencher `modelos/ficha-admissao.docx`
- [ ] Cadastrar o colaborador na planilha FUNC (aba CADASTRO)
- [ ] Confirmar data de início e loja de destino com a coordenadora
- [ ] Encaminhar para a etapa de [Onboarding](../02-onboarding/passo-a-passo.md)
