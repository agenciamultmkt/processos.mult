# Processos — Agência Mult

Repositório com o passo a passo padrão e os arquivos-modelo (editáveis) dos processos da agência, organizado por área — como abas de uma planilha.

## Áreas

- **[RH](RH/)** — recrutamento, contratação e onboarding de colaboradores
  - [Contratação](RH/contratacao/passo-a-passo.md) — do briefing da vaga até a admissão
  - [Onboarding](RH/onboarding/passo-a-passo.md) — textos, cartas, uniforme, EPI
- **[Gestão](GESTAO/passo-a-passo.md)** — Trade Pro, grupos, monitoramento do colaborador já ativo
- **[Operacional](OPERACIONAL/)** — uniforme, EPI, equipamentos, brindes (em construção)
- **[Comercial](COMERCIAL/)** — propostas, roteirização, precificação para clientes (em construção)

## Como usar

- Cada área é uma pasta (uma "aba"). Dentro dela: `passo-a-passo.md` (o checklist) e `modelos/` (os arquivos que você preenche a cada uso).
- Para editar um `passo-a-passo.md`: abra o arquivo aqui no GitHub e clique no ícone de lápis ("Edit this file") — não precisa saber usar git.
- Para usar um modelo: baixe o arquivo de `modelos/`, preencha no Word/Excel normalmente, e suba a versão preenchida de volta arrastando o arquivo pela interface do GitHub.

## Nota importante

Os arquivos dentro de `modelos/` são **modelos em branco** — evite sobrescrever o modelo original com os dados de um caso específico. Operacional e Comercial ainda não têm conteúdo — são as próximas áreas a documentar.
